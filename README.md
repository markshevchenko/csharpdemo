# csharpdemo
Разные интересности C#

Проект был создан при подготовке воркшопа для весенней (летней) конверенции DotNext 2022. В результате наклоадок, воркшоп так и не состоялся, материалы были использованы при подготовке к осенней конференции DotNext 2022.

**ExpressionTrees.csx** — рассказываю о деревьях выражений. В качестве примера реализую функцию символического вычисления производной функции.

**Streams.csx** — рассказываю об итераторах так, как они представлены в SICP (Книга Структура и интерпретация компьютерных программ), с необычной для C#-программиста точки зрения. Показываю способ быстрого вычисления числа &pi;, основанный на комбинировании бесконечных последовательностей и их модификаторов.
